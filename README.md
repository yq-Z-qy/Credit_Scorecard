# Credit_Scorecard
# 信贷评分卡构建与模型 PSI 监控

基于 Kaggle 经典的 Give Me Some Credit 真实信贷数据集，使用 Python 构建的完整风控评分卡管线。

## 项目流程
1. **数据清洗**：处理缺失值与异常值。
2. **特征工程**：使用 `toad` 库进行卡方分箱，计算 WOE 与 IV 值，筛选高预测力特征。
3. **模型构建**：使用 `Scikit-learn` 构建逻辑回归评分卡模型，测试集 **AUC 达 0.86，KS 达 0.57**。
4. **分数映射**：设定基准分 600，PDO 为 50，将违约概率转化为标准信用评分（300-850分）。
5. **模型监控**：编写 Python 脚本计算 PSI（群体稳定性指标），设定阈值（>0.25告警），自动输出监控报表。
